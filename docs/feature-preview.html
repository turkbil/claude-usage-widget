Başlık içeriği.
Örnek · canlı önizleme · her veri bağımsız

Her veri için üç seçenek var: Gizle, Yazı ya da Donut. İstediğin kombinasyonu kur — hepsi yazı, hepsi donut, ya da karışık. Haftalık metrikler amber, 5 saatlik olanlar yeşil renkle çizilir, böylece menü çubuğunda kolayca ayırırsın.

08
Çoklu tarayıcı.
Örnek · cookie kaynakları

Chromium ailesi (Chrome, Brave, Edge, Arc) aynı şifreli cookie düzenini paylaşır. Firefox ve Safari farklı motorlar kullanır — Firefox'ta cookie'ler SQLite içinde düz metin, Safari'de ise binary format. Birden fazla tarayıcı açıksa widget ilk geçerli oturumu bulduğu yerden okur.

↑ İlk aktif oturumu bulan tarayıcı kazanır. Safari için bir kerelik Sistem Ayarları → Gizlilik & Güvenlik → Tam Disk Erişimi.

09
Gizlilik & güncelleme.
Örnek · sıkıcı ama gerekli ayarlar

Görünmeyen ama gerekli kısımlar. Yeni sürüm uyarısı GitHub Releases'i kontrol eder (üyelik/imza gerektirmez). Çökme raporları için macOS'in kendi crash log'larına güveniyoruz — kullanıcı sorun bildirirken o dosyayı paylaşır. Yerel HTTP ve MCP modları, başka araçların — Claude Code dahil — canlı veriyi görmesini sağlar.

Yeni sürüm uyarısı
GitHub Releases'i günde bir kontrol eder. Yenisi varsa dropdown'a küçük rozet çıkar — tıklayınca Releases sayfası açılır, kullanıcı manuel indirir.
Yerel HTTP endpoint :9123
GET localhost:9123/usage · JSON · sadece localhost.
MCP sunucu modu
get_usage aracını sunar — Claude Code kendi limitini görebilir.
Çökme raporu

Üçüncü taraf hata izleme (Sentry vb.) yok. Çökme yaşarsan macOS otomatik olarak ~/Library/Logs/DiagnosticReports/ altına .ips dosyası yazar. GitHub issue açarken o dosyayı yapıştır — bir kere yeter.
